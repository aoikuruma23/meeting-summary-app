## 1. どんなアプリで、何を目的としているか

**一言で**：会議を録音するだけで、AIが自動で文字起こし＆構造化要約を作る「議事録作成の自動化ツール」。

**解決する課題（ペイン）**
- 議事録の作成・清書に時間がかかる
- 議事録係になると会議に集中できない／発言を聞き逃す
- 「決定事項」「誰が・いつまでに何をやるか（アクション）」が後から曖昧になる
- 共有用にPDF/Wordへ整える手間

**提供価値（ベネフィット）**
- 録音→停止だけで、要点・決定事項・アクションアイテムが整理された議事録が手に入る
- 会議そのものに集中できる
- 日本語に最適化された構造化要約で、そのまま共有できる
- 機密性の高い会議でも使えるプライバシー設計（→ 第6章）

## 3. 主な機能（事実ベース）

### コア機能
1. **ブラウザ録音**：ブラウザ上でワンクリック録音。長時間音声は自動でチャンク分割して処理。
   - 対応音声形式：WAV / MP3 / M4A / AAC / FLAC / OGG / WebM、1ファイル最大100MB
2. **AI文字起こし**：OpenAI Whisper による日本語音声認識。
3. **AI自動要約（構造化）**：会議の文字起こしから、以下の構成で要約を自動生成。**転写にない情報は創作しない**設計（「記載なし」と明示）。
   - `会議概要` / `決定事項` / `議論の詳細` / `アクションアイテム（担当・期限・内容）` / `次回の議題・持ち越し課題`
4. **履歴管理**：過去の議事録（要約・全文転写）をいつでも閲覧。
5. **エクスポート**：要約を **PDF / Word（.docx）** で出力（日本語フォント対応）。※プレミアム機能

### ログイン手段（3種）
- メールアドレス（認証コード方式）
- Googleログイン
- LINEログイン

### 補助機能（バックエンド実装あり／LP掲載前に「UIで使えるか」を要確認）
- 話者別の要約
- 参加者の発言貢献度分析
- 会議効率スコア（時間効率・参加率・決定効率など）＋改善提案
> ⚠️ これらは実装は存在するが、現行UIで一般ユーザーが使える状態か未確認。**確認できるまでLPの主要訴求にしない**こと。「順次提供予定の機能」程度の扱いが安全。

## 4. 使い方（4ステップ）

1. **録音開始** — ホームの「録音開始」をクリックして会議を録音
2. **録音中** — 音声を取り込み（静かな環境ほど精度向上）
3. **録音停止** — 停止すると自動で文字起こし＆要約を生成
4. **結果確認** — 履歴ページで要約を確認、PDF/Wordでダウンロード・共有

**活用シーン**
- 🏢 企業会議（取締役会・部門会議・プロジェクト会議）
- 👥 チームミーティング（リモート/ハイブリッド）
- 🎓 教育・研修・セミナー
- 📊 顧客インタビュー・市場調査・ユーザーリサーチ
- 🤝 士業/コンサルの面談・商談記録

## 6. 差別化・強み（LPの主役にすべきポイント）

### ⭐ プライバシー/セキュリティ設計（最大の差別化・機密会議でも安心）
※以下は**実装済みの事実のみ**。これ以外のセキュリティ表現は使わないこと（第9章参照）。
- 通信は **HTTPS** で暗号化
- AIには **OpenAI API** を使用 → **入力データはAIの学習に使われない**（API既定）。さらに OpenAI ダッシュボードへの会話ログ保存も**オフに設定済み**
- OpenAIと **データ処理契約（DPA）を締結済み**（処理者として処理・データ販売なし・侵害通知・契約終了後削除）
- **文字起こし・要約の完了後、サーバ上の録音音声を自動削除**（生音声を残さない）
- サーバログに会議内容（要約本文）を残さない設計

→ 訴求例：「**機密会議でも使える、プライバシー配慮のAI議事録**」「あなたの会議内容はAIの学習に使われません」

### その他の強み
- 日本語に最適化された**構造化要約**（決定事項・アクションを自動抽出）
- **¥999/月**の手頃な価格
- インストール不要、ブラウザだけで完結
- Google / LINE / メール の**選べるログイン**

- **Q. 無料で使えますか？** A. はい。登録から一定期間・回数を無料でお試しいただけます（プレミアムは月額¥999）。
- **Q. 録音時間の上限は？** A. 無料は1回30分、プレミアムは1回2時間まで。

- **Q. 対応ブラウザは？** A. Chrome / Firefox / Safari など主要ブラウザ（PC・タブレット）。
- **Q. 出力形式は？** A. 要約はPDF・Word形式でダウンロードできます（プレミアム）。

- **Q. ログイン方法は？** A. メール・Google・LINEから選べます。

## 9. ⚠️ コピー作成上の禁止・要修正事項（必読）

現行サイトに以下の表記があるが、**実装と一致しない／根拠がないため、新LPでは使用禁止 or 要修正**。誇大広告（景品表示法）・虚偽表示のリスクがあるため厳守。

| 現行の表記 | 問題 | 新LPでの扱い |
|-----------|------|-------------|
| **「ChatGPT 4.0使用」** | 実装は `gpt-3.5-turbo`。GPT-4ではない | **使用禁止**。「ChatGPTによる要約」等、モデル名を断定しない表現に |
| **「精度99%」「99%以上」** | 計測根拠なし | **使用禁止**。「高精度な日本語認識」等の定性表現に |
| **「AES-256暗号化」（データ暗号化）** | 録音音声・転写・要約は現状サーバで平文保存（保管時暗号化は未実装） | **使用禁止**。第6章の実装済み事実のみ記載 |
| **「処理時間5分」** | 環境依存・根拠不明 | 数値を断定しない。「最短数分で」程度なら可だが推奨は明記回避 |
| **「Google Driveに保存」** | 現状は自社DBに保存。Drive連携が稼働中か未確認 | **要確認**。確認できるまで「履歴に自動保存」と表現 |
| お客様の声・導入実績 | 実績データなし | ダミーを作らない。出るまで省略 |

> 補足：もし「GPT-4クラス使用」「高品質」を訴求したいなら、先にコード側のモデルを `gpt-4o` 等へ更新すること（別途要相談）。表記を実態に合わせるのが原則。
